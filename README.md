# Classical Machine Learning Models

This repository contains my implementations of classical machine learning algorithms using Python and scikit-learn.  
All notebooks were created and executed in Google Colab as part of my ML learning journey.

## Contents
- Data preprocessing  
- Supervised learning models (KNN, SVM, Logistic Regression, Decision Trees, Random Forests, etc.)
- Unsupervised learning (Clustering, PCA, Dimensionality Reduction)

## Goal
To build a strong foundation in classical ML by training 20–25 models and documenting their behavior through experiments.
